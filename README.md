# ByteFortix Guardian

Personal security scanner for Linux systems.

## What it detects
- Open dangerous ports
- Remote access tools (AnyDesk, TeamViewer)
- Firewall misconfigurations  
- Suspicious background processes
- Outdated system packages

## How to run
git clone https://github.com/kaifhoda1/bytefortix-guardian
cd bytefortix-guardian
python3 scanner.py

## Who is it for
Cybersecurity students and privacy-conscious Linux users.
